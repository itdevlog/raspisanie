# 📱 PWA Виджет расписания

## Что это

PWA (Progressive Web App) виджет — это возможность добавить расписание на главный экран телефона как отдельное приложение. Виджет автоматически обновляется и показывает актуальное расписание без открытия Telegram.

---

## 🚀 Как установить

### iPhone (iOS 16.4+)

**Вариант 1: Через Safari (рекомендуется)**

1. Откройте Mini App бота в Safari
2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх)
3. Выберите **«На экран «Домой»**
4. Подтвердите название «Расписание»
5. На главном экране появится иконка

**Вариант 2: Через виджет страницы**

1. Откройте Mini App
2. Нажмите кнопку **«📲 Установить приложение»** (появится если доступно)
3. Следуйте инструкциям iOS

**Вариант 3: iOS Shortcuts (для продвинутых)**

1. Откройте приложение **Shortcuts** (Команды)
2. Создайте новую команду:
   - Действие: `GET https://YOUR_BOT_URL/api/widget/USER_ID`
   - Действие: `Show Result` или `Quick Look`
3. Добавьте команду на главный экран как виджет

---

### Android

**Вариант 1: Через Chrome**

1. Откройте Mini App бота в Chrome
2. Нажмите **⋮** (три точки) → **«Добавить на главный экран»**
3. Подтвердите название
4. Виджет появится на главном экране

**Вариант 2: Через кнопку установки**

1. Откройте Mini App
2. Нажмите **«📲 Установить приложение»**
3. Chrome предложит добавить ярлык

**Вариант 3: KWGT виджет (требует настройки)**

1. Установите [KWGT Kustom Widget](https://play.google.com/store/apps/details?id=org.kustom.widget)
2. Создайте новый виджет
3. Добавьте веб-запрос к `/api/widget/{user_id}`
4. Настройте отображение по своему вкусу

## 🔗 Прямая ссылка на виджет

Откройте в браузере:

```
https://YOUR_BOT_URL/widget.html?user_id=YOUR_TELEGRAM_ID
```

Где:
- `YOUR_BOT_URL` — URL вашего Mini App (из `.env` → `WEBAPP_URL`)
- `YOUR_TELEGRAM_ID` — ваш Telegram user ID (можно узнать у бота @userinfobot)

- **Дата** сегодня

  - Номер урока
  - Время начала

  - ⚫ Зачёркнутый отменённый урок
- **Количество замен** сегодня (если есть)

## 🔄 Авто-обновление

Виджет автоматически обновляется:
- **Каждые 5 минут** — проверка новых данных
- **При открытии** — всегда свежие данные
- **При получении push** (если настроено) — мгновенное обновление

## ⚙️ Настройки

### Время обновления

По умолчанию 5 минут. Можно изменить в `widget.html`:

```javascript
setInterval(loadWidget, 5 * 60 * 1000);  // 5 минут
```

### Кэширование

Service Worker кэширует данные для офлайн-доступа. При отсутствии интернета виджет покажет последнюю загруженную версию.

## ❓ FAQ

**Q: Виджет не обновляется**  
A: Проверьте что `WEBAPP_URL` настроен (HTTPS обязателен). Откройте Mini App в браузере — данные должны грузиться.

**Q: iOS не показывает кнопку установки**  
A: Требуется iOS 16.4+. Или используйте Safari → «На экран Домой».

**Q: Как узнать свой user_id?**  
A: Напишите боту @userinfobot в Telegram.

**Q: Можно ли показывать расписание на завтра?**  
A: Да, добавьте параметр `?date=dd.mm.YYYY` к URL виджета.

**Q: Виджет показывает старый класс**  
A: Обновите данные в боте (выберите класс заново) и перезагрузите виджет.

## 🔒 Безопасность

- API endpoint требует заголовок `X-Telegram-Init-Data` с валидной HMAC-подписью Telegram; `user_id` из подписи сверяется с `{user_id}` в URL, иначе 403
- Рекомендуется использовать HTTPS (обязательно для PWA)
- Данные кэшируются локально на устройстве
