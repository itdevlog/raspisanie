# Как пользоваться

Два способа смотреть расписание: **Telegram-бот** и **публичный сайт** (без входа).

---

## 🤖 Telegram-бот

### Начало

1. Откройте бота в Telegram (ссылку даёт администратор школы) и нажмите **`/start`**.
2. Выберите **школу**, затем **класс** (или учителя/кабинет).
3. Появится расписание на **сегодня**. Кнопками переключайте **Завтра / Неделю**.

Выбранные школа и класс запоминаются — в следующий раз расписание откроется сразу.

### Расписание

- 📅 **Класс** — уроки на день/неделю с временем, предметом, учителем и кабинетом.
- 👨‍🏫 **Учитель** — расписание преподавателя (учитывает его замены).
- 🚪 **Кабинет** — какие уроки идут в кабинете; кнопка **«Свободный кабинет»** покажет свободные
  кабинеты на текущий/следующий урок.
- 🔄 **Замены** подсвечиваются: `🔄 6. 13:00-13:45 • Математика … → Биология …`; снятие — `↩️ … — замена снята`.
- 🗓️ **Переносы и каникулы** отображаются как на сайте.

### Уведомления и подписки

- 🔔 **Подписка** на учителя или кабинет — кнопка «Подписаться» в расписании. Придут уведомления
  о заменах по этому учителю/кабинету. Список подписок — в **`/settings`**.
- ⏰ **Напоминания об уроках** — «через N мин начнётся урок …» (тумблер в `/settings`).
- 📋 **Утренний дайджест** — расписание на день с заменами за час до первого урока.
- 🌙 **Тихие часы** — не беспокоить ночью (по умолчанию **22:00–7:00**); настраивается в `/settings`.

### Полезные команды

| Команда | Зачем |
|---------|-------|
| `/start` | Главное меню |
| `/week 5и` | Расписание класса на неделю |
| `/status` | Актуально ли расписание по школам |
| `/settings` | Уведомления, напоминания, дайджест, тихие часы, подписки |
| `/cancel` | Сбросить ввод и вернуться в меню |

## 🌍 Публичный сайт

Откройте адрес сайта в браузере телефона — вход не нужен.

### Расписание

- Выберите **школу** (кнопки с номерами) и **класс/учителя/кабинет**.
- Переключайте **Сегодня / Завтра / Неделю / Месяц**.
- **Свайп** влево/вправо листает дни (в неделе — недели, в календаре — месяцы).
- 🔍 **Поиск** по классам/учителям/кабинетам; 🚪 **свободные кабинеты**.
- ⭐ **Избранное** — сохраните часто нужные классы/учителей/кабинеты.
- 🔗 **Поделиться** — ссылка вида `/s/{школа}/{класс}?date=…` открывает нужный день.

### Настройки (⚙)

- 🎨 **Оформление**: скин (Классика / Минимализм / Тёмная / Контрастная / Молодёжный), акцент, размер шрифта.
- 📐 **Вид расписания**: Компактный / Карточки / Таблица / Таймлайн / Сейчас и далее.
- 🔔 **Уведомления** (Web Push) о заменах + «🌙 Не беспокоить ночью» (22:00–7:00).

### Установка на телефон

- **Android (Chrome):** меню ⋮ → «Установить приложение» / «Добавить на главный экран».
- **iOS (Safari):** «Поделиться» → «На экран „Домой“».

Появится иконка — сайт открывается как приложение и работает офлайн (показывает последние данные).

### Уведомления о заменах (Web Push)

1. В ⚙ → **Уведомления** нажмите «Включить уведомления» и разрешите их в браузере.
2. Подпишитесь на класс/учителя.
3. При появлении замены придёт push; ночью (22:00–7:00) уведомления не беспокоят.

## ❓ Частые вопросы

**Нужен ли аккаунт?** Нет. Бот — обычный Telegram-чат; сайт открывается без входа.

**Откуда данные?** Из системы Nikasoft (Ника-Люкс), которую ведёт школа. Обновление — раз в час
и вручную администратором.

**Почему нет уроков?** Возможно, каникулы/выходной или расписание ещё не загружено — проверьте
дату и `/status`.

**Не приходят уведомления?** Проверьте подписку и разрешение на уведомления; тихие часы
могут отложить их до утра.

**Расписание устарело?** В боте `/status` покажет возраст данных; администратор может обновить вручную.
