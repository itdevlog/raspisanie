2. **`return-value` на `object` — 1 шт.**
   `config/schools.py:36`: `(SCHOOLS_CONFIG.get(...) or {}).get('name')` даёт `object`.
   Добавлен `cast(str, config_name)` (инвариант известен: значение из конфига — строка).

3. **`operator` (`in` по `Any | None`) — 1 шт.**

## Конфигурация mypy

В `mypy.ini` добавлен `follow_imports = silent`. Это делает проверку самодостаточной для
явно перечисленных модулей: `mypy services config core database bot.py` проверяет только их,
а ошибки в импортируемых модулях `handlers/` (следующий проход) не всплывают. Проверка
производственных модулей при этом не отключена (проверено внесением намеренной ошибки —
она диагностируется). Явный `mypy handlers/...` по-прежнему анализирует обработчики.

## Хелперы сужения

`require_user_data` (сужение Optional-полей PTB через `assert`). Использованы в `bot.py`;
предназначены для прохода по обработчикам. Файл проходит mypy без ошибок.
